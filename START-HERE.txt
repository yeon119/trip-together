모여서 떠나 — 친구들과 여행 날짜 정하기

1. start-preview.cmd를 더블 클릭합니다. Node.js가 필요합니다.
2. 브라우저에서 http://127.0.0.1:4173 에 접속합니다.
3. Firebase 설정 전에는 해당 브라우저에만 저장되는 체험 모드입니다.
4. DEPLOY.html을 열면 Firebase 연결 및 GitHub Pages 배포 과정을 볼 수 있습니다.

포함 기능
- 여행 방 만들기, 후보 기간·여행 일수·예정 인원 설정
- 달력에서 가능한 날짜 선택, 본인 응답 저장·수정·삭제
- 여행 전체 기간의 참여 가능 인원에 따른 상위 5개 일정 추천
- 방장 일정 확정 및 취소, 확정 후 응답 잠금
- Firebase 연결 시 초대 링크와 실시간 응답 동기화
- 휴대폰 화면 지원

검증 상태
- 날짜 계산, 입력 검증, HTML 이스케이프 자동 검사 6개 통과
- 체험 모드의 생성·저장·추천·확정·취소·새로고침 유지 확인
- 390px 모바일 뷰포트에서 시작 화면과 여행 방 가로 넘침 없음 확인
- 실제 Firebase 익명 로그인, 방 생성, 두 참가자 응답 저장·수정·실시간 동기화 및 새로고침 유지 확인
- 다른 참가자 응답 수정, 비방장 일정 확정, 방 목록 조회, 미인증 조회가 거부됨을 확인
- Firestore의 모든 가능한 보안 조건을 완전 검증한 것은 아님
- 외부 인터넷 배포는 아직 하지 않음

익명 인증은 같은 브라우저에서만 사용자 권한을 유지합니다.
방 링크를 아는 사람은 해당 방 응답을 볼 수 있습니다.
서비스 계정 키, 비밀번호를 코드에 넣지 마세요.
